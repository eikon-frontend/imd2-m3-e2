# M3-E2 : une critique, deux formats

Le HTML, les polices et les couleurs sont déjà en place. Il reste la mise en page.

## Démarrer le projet

Dans le terminal de VS Code, à la racine du projet :

```bash
npm install
npm start
```

## Ce qu'il y a à faire

Maquette : [M3-E2](https://www.figma.com/design/p7wE0JpgOLkLrEARIPCt6l/M3-E2?node-id=0-1)

Dans `src/style.css`, intégrez d'abord la version mobile, sans media query. Ajoutez ensuite une seule media query pour la version desktop.

Utilisez des `rem` pour les tailles de texte, et aucune largeur fixe en `px`. La citation doit s'adapter à toutes les largeurs, et cesser de s'élargir sur un grand écran.
